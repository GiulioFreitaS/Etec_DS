## ▶️ Como rodar os projetos

**Java**
```bash
cd 2_ano/DS/NOME-DO-PROJETO
javac *.java
java NomeDaClassePrincipal
```
Requer o [JDK](https://adoptium.net) instalado. Também funciona abrindo a pasta numa IDE (IntelliJ, Eclipse ou VS Code).

**PHP**
- Instale o [XAMPP](https://www.apachefriends.org) e copie a pasta do projeto para `htdocs`.
- Inicie **Apache** e **MySQL** pelo painel do XAMPP.
- Se o projeto usar banco, importe o arquivo `.sql` (quando existir) pelo `phpMyAdmin`.
- Acesse `http://localhost/NOME-DO-PROJETO`.

**HTML, CSS e JavaScript**
Abra o `index.html` no navegador.
